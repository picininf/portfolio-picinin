# portfolio-picinin
Personal portfolio website showcasing my web development projects, skills, and experience.

Site: https://picininf.github.io/portfolio-picinin/

## Estrutura

| Arquivo | Para que serve |
|---|---|
| `index.html` | Conteúdo do site (seções, projetos, certificados) |
| `style.css` | Visual, temas claro/escuro e responsividade |
| `script.js` | Arco-íris animado, menu, tema e modal de ajustes |
| `*.jpg` | Imagens otimizadas (avatar, projetos e certificados) |

Para adicionar um projeto, copie um bloco `<article class="project-card">` na seção `#projetos`
e coloque a imagem (JPG com cerca de 960px de largura) na raiz, ao lado do `index.html`.
